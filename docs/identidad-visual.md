# Identidad visual del Centro de estadísticas

La marca pública es **Centro de estadísticas**. El nombre interno del repositorio y las variables `CASA_MORRA_*` permanecen para conservar la compatibilidad operativa.

La torre integra tres barras ascendentes. De izquierda a derecha representan **partidas perdidas, empatadas y ganadas**: rojo, gris y azul. Hay dos recursos transparentes, ambos originales del proyecto:

- `dist/assets/rook-large.png`: barras rellenas roja, gris y azul, de menor a mayor altura. Se usa en las cabeceras pública y administrativa, el favicon y como emblema decorativo de mayor tamaño en el encabezado de estadísticas.
- `dist/assets/rook-small.png`: variante histórica con barras en negativo, conservada como recurso compatible pero no utilizada por la interfaz actual.

La marca textual no está incorporada en las imágenes: permanece como HTML para que sea legible, traducible y accesible. El enlace principal tiene un nombre accesible propio. La imagen decorativa grande usa texto alternativo vacío para no repetir esa información.

El realce de navegación y etiquetas usa el rojo de las partidas perdidas (`#b84f55`). Sobre el encabezado oscuro se usa una variante clara del mismo rojo (`#f0a5a7`) para conservar contraste de lectura; en el panel administrativo claro se usa una variante oscura (`#8b3038`). Los dos PNG y sus hashes están registrados en [procedencia](procedencia-demo.md).
