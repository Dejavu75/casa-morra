# Identidad visual del Centro de estadísticas

La marca pública es **Centro de estadísticas**. El nombre interno del repositorio y las variables `CASA_MORRA_*` permanecen para conservar la compatibilidad operativa.

La torre integra tres barras ascendentes. Hay dos recursos transparentes, ambos originales del proyecto:

- `dist/assets/rook-small.png`: barras como espacios negativos. Se usa en las cabeceras pública y administrativa y como favicon; debe seguir legible en un cuadrado pequeño y sobre fondo claro.
- `dist/assets/rook-large.png`: barras rellenas roja, azul y dorada, de menor a mayor altura. Se usa como emblema decorativo de mayor tamaño en el encabezado de estadísticas para pantallas amplias.

La marca textual no está incorporada en las imágenes: permanece como HTML para que sea legible, traducible y accesible. El enlace principal tiene un nombre accesible propio. La imagen decorativa grande usa texto alternativo vacío para no repetir esa información.

La variante de barras coloreadas no debe reducirse al tamaño de favicon: sus tres colores pierden diferenciación. La variante pequeña mantiene el contraste mediante los huecos, incluso en monocromo. Los dos PNG y sus hashes están registrados en [procedencia](procedencia-demo.md).
