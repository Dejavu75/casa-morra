Administración

Cargá y corregí jugadores, torneos, partidas y estadísticas.

Acceso administrativo

Este panel funciona únicamente desde el equipo servidor; la web pública permanece de solo lectura.

01 · Resultado

Cargar partida nueva

Solo se ofrecen torneos con una tabla completa para sumar el resultado. Los torneos históricos siguen visibles en las estadísticas.

02 · Planilla

Completar partida existente

Se actualiza la misma partida. El resultado y la tabla del torneo no se vuelven a sumar.

03 · Corrección

Corregir resultado de una partida

La partida conserva su identidad y sus jugadas. La tabla se ajusta automáticamente; no se eliminan registros.

04 · Jugadores

Cargar o editar jugador

La dirección del perfil permanece estable si se corrige el nombre. No se eliminan jugadores con historial.

04 · Temporadas

Cargar o editar temporada

05 · Torneos

Cargar o editar torneo

Participantes

Elegí al menos dos jugadores. Una vez inscriptos, no se quitan desde este formulario para preservar resultados.

07 · Descansos

Cargar o editar descanso

El descanso suma puntos oficiales, pero no cuenta como partida ganada o empatada.

08 · Distinciones

Cargar o editar título

09 · Tabla histórica

Corregir puesto y puntos

Solo corrige tablas históricas sin partidas individuales. No inventa resultados ni altera otras filas.

06 · Torneo

Modalidad de torneo

Texto libre, por ejemplo 20'+3. Dejá el campo vacío para quitar una modalidad cargada.
